# FLiCK 이미지 자동 업로드 구조

이 폴더는 사이트 이미지 전용 폴더입니다.

## 목표
이미지 생성 후 별도 수동 작업 없이 저장소에 반영할 수 있도록 GitHub Actions 기반 업로드 구조를 사용합니다.

- home-zodiac.webp
- home-astrology.webp
- home-psychology.webp
- home-lucky.webp
- test-love.webp
- test-stress.webp
- test-choice.webp
- test-animal.webp
- test-message.webp
- page-fortune.webp
- page-psychology.webp
- page-mbti.webp
- page-tarot.webp
- page-community.webp

## 주의
GitHub Actions는 저장소에 전달된 이미지 파일을 자동으로 정리·검증하고 Cloudflare 배포 대상으로 유지합니다.
