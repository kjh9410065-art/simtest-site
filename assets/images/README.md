# FLiCK 사이트 이미지 업로드 폴더

이 폴더에 사이트에서 사용할 이미지를 업로드합니다.

## 업로드 규칙
- PNG / JPG / WebP 권장
- 이미지 1개 = 사이트 요소 1개
- 이미지 안에 글자, 버튼, UI를 넣지 않습니다.
- 파일명은 아래처럼 역할을 명확하게 지정합니다.

## 홈 화면
- `home-hero.webp` → 메인 히어로
- `home-zodiac.webp` → 띠 운세
- `home-astrology.webp` → 별자리 운세
- `home-psychology.webp` → 심리테스트
- `home-lucky.webp` → 행운의 아이템
